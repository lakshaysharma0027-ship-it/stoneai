一 2025
镜像城市
Mirror City

A real-time urban data visualization installed across the facade of Shanghai Tower. 12,000 LED nodes driven by live transit, weather, and social signal feeds — the building becomes a nervous system.

二 2024
语言残骸
Language Debris

An ML model trained exclusively on deleted WeChat messages — the ghosts of unspoken thoughts. Outputs rendered as generative calligraphy, each stroke weighted by emotional valence score.

Machine Learning Generative Art NLP

三 2024
身体协议
Body Protocol

Wearable biosensor network translates physiological noise — heartbeat, galvanic response, breath — into a shared sonic environment. Performed at Centre Pompidou, Paris. Audience wears the instruments.

Wearables Performance Biometric Sound

四 2023
空白记忆
Blank Memory

A browser-based archive of images that automatically degrade over time, simulating the neurological process of forgetting. Revisiting a page accelerates the decay — attention as erasure.

Web Art Canvas API Conceptual
Open ↗
五 2022
系统故障
System Failure

Interactive installation where gallery visitors collectively break a running program through touch. The accumulated errors become the final artwork — a collaborative portrait of disruption.

关于 About

我在系统的缝隙中工作。代码是材料，空间是画布，时间是媒介。

I work in the gaps between systems. Code as material, space as canvas, time as medium. My practice exists at the point where technology loses its neutrality and becomes something uncomfortably alive.
